# 초기 버전 흐름과 확인 범위

이 표는 남아 있는 버전 정리 자료와 검증 기록을 기반으로 작성했다. 모든 항목이 Git 태그나 독립 릴리스로 남아 있다는 뜻은 아니다. 날짜가 확실하지 않은 항목에는 추정 날짜를 붙이지 않았다.

| 단계 | 당시 다룬 내용 | 함께 남겨야 할 한계 |
| --- | --- | --- |
| v0.1 | 작은 대화창, API 대화, 화면 영역 공유, Blender와 함께 쓰는 흐름 | 독립 로컬 실행 방식이 아니었고 원본 실행 코드는 보존되지 않음 |
| v0.2 | 한글 입력기 연결과 입력창 개선 | 입력 개선 단계. 원본 실행본 미보존 |
| v0.3 | API 키 없이 현재 AI 채팅을 통해 요청과 답을 주고받는 반자동 연결 | 별도 확인 요청이 필요한 방식. 상시 연결 아님 |
| v0.4 | Ollama + Qwen3-VL 2B Instruct로 독립 로컬 실행 | 반복 응답과 이해력 문제가 뒤따름. 원본 실행본 미보존 |
| v0.5 | 취향 메모, 대화·작업 기록, 기억 관리, 반복 응답 보완 | 기억 저장은 모델 가중치 재학습이 아님. 원본 실행본 미보존 |
| v0.6 | 일반 대화·화면 설명·글쓰기·번역·문제 해결로 범위 확대 | 일반 앱 클릭·입력은 이 단계의 지원 범위가 아님 |
| v0.7 | 나·너 지칭, 사용자 정보의 출처, 모호한 요청 확인 | 특정 역할 오류 보완을 전반적 이해력 향상의 증거로 볼 수 없음 |
| v0.8 | 잠정 가설과 단정 구분, 최신 선호 우선, 오래된 상충 답변 제외 | 당시 실행본을 별도 보관했던 기록은 있으나 이후 정리됨. 현재 공개 가능한 원본 스냅샷으로 보장하지 않음 |
| v0.9 | 잘린 일반 답변의 제한적 이어 쓰기, 빈 응답 복구 | 무한 재시도하지 않으며 불완전한 조작 응답은 실행하지 않음 |
| 1.0에 해당하는 이정표 | 8B 모델 전환, 최신 단일 실행본 정리, 기억·지칭·오류 화면의 제한된 사례 검증 | 별도 1.0 Git 태그를 보존한 기록은 확인하지 못함. 전반적 이해력이나 화면 정확도 보장 아님 |

## 당시 8B 검증에서 확인한 것

기록상 검증일은 2026년 11월 3일이다. 아래 시간은 원래 검증 결과를 반올림한 것이며 재측정값이 아니다.

| 사례 | 기록상 결과 | CPU 응답 시간 |
| --- | --- | --- |
| 저장된 요약 길이 선호 참고 | 해당 선호를 반영한 답변 | 약 12초 |
| 가설을 밝히고 확인하는 대화 방식 | 저장된 방식을 설명 | 약 23초 |
| 부탁한 사람 / 행동할 사람 구별 | 해당 짧은 문제에서 정답 | 약 11초 |
| 오류 화면 읽기 | `ERROR 503` 인식 | 약 100초 |

이는 소수의 기능 확인 사례다. 반복 측정 평균, 표준화된 벤치마크, 사용자 연구, 모델 학습 전후 비교가 아니다.

## 공개 범위

글에 필요한 기능과 실패 사례만 재작성했다. 원본 대화 전체, 개인 메모, 데이터베이스, 화면, 테스트 대상의 개인 정보, 내부 경로와 계정 정보는 올리지 않았다.

1.0 이후의 검증 결과가 같은 로컬 문서에 함께 남아 있더라도 이번 글의 성과로 합치지 않았다. 당시 원본 소스가 없는 버전의 태그와 릴리스도 새로 만들어 소급하지 않는다.

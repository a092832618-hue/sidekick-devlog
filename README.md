# Sidekick 개발일지

## AI 비서를 만들고 싶었는데, 일단 대화부터 배워야 했다

시작은 단순했다.

> 화면을 같이 보고, 옆에서 의견을 주고받고, 필요하면 직접 도와주는 AI가 있으면 좋겠다.

처음엔 Blender를 함께 다루고 싶었다. 그런데 만들다 보니 Blender보다 먼저 풀어야 할 문제가 생겼다.

**한글 입력. 따라 말하기. “나”와 “너” 구별하기. 그리고 문장을 끝까지 말하기.**

이 저장소는 Sidekick을 만들며 겪은 시행착오와 아이디어를 차례로 기록하는 곳이다. 첫 번째 이야기는 초기 실험부터 **1.0에 해당하는 로컬 8B 기반 출발점**까지를 다룬다.

### 첫 번째 이야기

**[EP.01 — 비서를 부탁했는데 앵무새가 왔다](docs/01-road-to-v1.md)**

1. Blender 옆에 작은 대화창을 놓아 보자
2. 잠깐, 한글이 안 써지는데?
3. API 키 없이 혼자 움직이는 AI를 원했다
4. AI가 내 말을 그대로 따라 하기 시작했다
5. 너는 Sidekick이고, 나는 사용자라고!
6. “질문해 줘”라는 부탁부터 이해하지 못했다
7. 답변이 끝나지 않는 문제와 모델 교체
8. 완성 대신 첫 출발선을 정했다

### 기록을 읽는 방법

- **[초기 아이디어 노트](docs/03-idea-notes.md)** — 왜 이런 AI를 만들고 싶었는지, 무엇을 고집했는지.

### 이 기록의 범위

이곳은 현재 **개발 이야기 중심의 저장소**다. 앱 설치 파일이나 1.0 당시의 소스 배포본이 아니다.

초기에는 같은 파일을 계속 고쳤기 때문에 일부 버전의 원본 실행본이 남아 있지 않다. 남아 있는 버전 정리 자료·검증 결과와 개발 대화를 바탕으로 흐름을 재구성했다. 대화 일부는 읽기 쉽게 발췌하거나 재구성했으며, 장면 사이의 유머는 편집 표현이다.

1.0 이후의 개발은 후속 글로 순서대로 올릴 예정이다. 이 첫 글에는 이후 기능을 이미 완성했던 것처럼 섞지 않았다.

개인 대화 전체, 기억 데이터베이스, 화면 캡처, 계정 정보, API 키와 로컬 파일 경로는 공개하지 않는다.

---

사용자가 원하는 것을 말하고, AI와 함께 만들고, 실제로 써 보고 다시 고치는 중이다.

**첫 목표는 거창한 만능 AI보다, 내 말을 제대로 듣는 작은 동료였다.**

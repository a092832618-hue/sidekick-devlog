# Sidekick 개발 진행 기록

- 기록 범위: 초기 Blender 조작 점검부터 로컬 8B 기반 1.0 단계까지.
- 기록 기간: 2026년 11월 2~3일, 한국 시간.
- 정리 방식: 요구 사항·구현·발생 문제·수정·검증·한계를 구분한 개조식 기록.
- 상세 내용: [Sidekick 1.0까지의 개발 진행 상황](docs/01-road-to-v1.md).
- 1.1 제작 요청 이후의 기능과 결과: 이번 기록에서 제외.
- 배포 범위: 문서만 제공. 1.0 앱 설치 파일이나 당시 원본 소스 배포본은 포함하지 않음.
- 버전 표기: v0.1~v0.9는 당시 버전 정리 자료를 따름. 1.0은 8B 전환·검증 완료 단계를 가리키며 보존된 Git 태그를 의미하지 않음.
- 원본 보존 상태: 초기 일부 실행 코드는 덮어쓰기되었고 이후 구버전 정리도 수행됨. 없는 실행본을 복원했다고 주장하지 않음.
- 기록 근거: 당시 사용자·개발 AI 대화, 버전 정리 스크립트, 검증 스크립트, 저장된 결과 파일.
- 검증 해석: 당시 보고와 저장된 측정 결과를 구분함. 재측정 결과나 전반적 성능 보장으로 해석하지 않음.
- 비공개 범위: 개인 대화 전체·기억 데이터베이스·화면 캡처·계정 정보·API 키·개인 PC 경로.
